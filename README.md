# کافه مکث — VC-030

اپ فارسی سفارش میز کافه، بدون وابستگی و بدون نیاز به نصب پکیج.

## اجرا

پیشنهاد برای تست مطمئن دو تب: Node.js را نصب داشته باشید، در پوشهٔ پروژه اجرا کنید:

```sh
node server.cjs
```

منوی مشتری: http://127.0.0.1:4173/?table=7

آشپزخانه: http://127.0.0.1:4173/?view=kitchen

هر دو لینک باید در **همان مرورگر، همان پروفایل و همان آدرس پایه** باز شوند. از لینک آشپزخانه در سربرگ هم می‌توانید استفاده کنید. شمارهٔ میز از URL خوانده می‌شود و از منوی انتخاب میز هم قابل تغییر است (۱ تا ۵۰).

فایل index.html مستقیماً هم باز می‌شود و fetch ندارد؛ اما اشتراک localStorage برای آدرس‌های file در مرورگرها یکسان نیست. برای نمایش قطعی ارتباط دو تب از سرور محلی بالا یا Live Server استفاده کنید. هاست و دیتابیس لازم نیست.

## امکانات

- منوی ۸ آیتمی با دسته‌بندی، تصویرسازی SVG داخلی، قیمت تومان و توضیح
- سبد با افزایش و کاهش تعداد، حذف با کاهش به صفر، جمع کل و یادداشت سفارش
- ثبت سفارش میز و نمایش وضعیت آماده‌سازی و آماده‌شدن در تب مشتری
- کسر موجودی در زمان ثبت نهایی، کنترل دوبارهٔ موجودی و جلوگیری از سفارش کالای تمام‌شده
- پنل آشپزخانه با سفارش‌ها، تاریخ شمسی، دکمهٔ آماده شد و ویرایش موجودی
- ناموجودکردن فوری و تأمین مجدد از پنل آشپزخانه
- همگام‌سازی بدون رفرش با رویداد storage
- قفل تراکنش Web Locks در مرورگرهای پشتیبان، برای جلوگیری از فروش دوبارهٔ آخرین آیتم در ثبت هم‌زمان دو تب
- رابط راست‌چین و واکنش‌گرا، ارقام فارسی، کنترل‌های دارای برچسب و حالت فوکوس

## تست

```sh
node test.cjs
```

تست‌ها منطق موجودی، جمع قیمت، اعتبارسنجی میز، سبد خالی، کمبود موجودی، رقابت بر سر آخرین آیتم، آماده‌شدن و تأمین مجدد را بررسی می‌کنند.

آزمون دستی تکمیلی: مشتری را روی میز ۷ باز کنید، لاته به سبد بیفزایید؛ در تب آشپزخانه لاته را ناموجود کنید؛ به تب مشتری برگردید، بدون رفرش باید «تمام شد» ببینید و ثبت سبد قدیمی هم باید رد شود. با کاهش تعداد به صفر سبد را اصلاح کنید. موجودی را ۱ کنید، یک لاته ثبت کنید، کاهش موجودی به صفر و رسیدن سفارش به آشپزخانه را ببینید. روی «آماده شد» بزنید و وضعیت مشتری را بررسی کنید. همین مسیر را در عرض موبایل هم طی کنید.

## حدود نسخه

داده‌ها روی همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها مشترک نیستند. پنل آشپزخانه ورود ندارد چون در دامنهٔ این تمرین نیست. در مرورگر فاقد Web Locks، عملیات هر تب همگام است ولی تضمین ثبت هم‌زمان چند تب وجود ندارد؛ Chrome یا Edge جدید روی localhost پیشنهاد می‌شود. سبد تا زمان ثبت فقط در حافظهٔ تب است؛ سفارش‌ها و موجودی پس از بستن صفحه باقی می‌مانند. تاریخ و وضعیت سفارش شخصی تا پایان نشست تب قابل مشاهده است. اعداد داخل کنترل عددی ویرایش موجودی ممکن است طبق تنظیم مرورگر لاتین باشند؛ متن‌های نمایشی فارسی‌اند.

ویدیوی واقعی ضبط‌شده در این بسته نیست؛ فایل DELIVERY.md سناریوی ضبط حدود دو دقیقه‌ای دارد. آزمون تصویری مرورگر خودکار به علت timeout اتصال پیش‌نمایش انجام نشد؛ تست منطق پاس شد؛ بررسی HTTP محلی هم به علت محدودیت اتصال محیط موفق نشد.
